# موقع معرض الأعمال (Portfolio) 📊

موقع معرض أعمال شخصي بسيط، أنيق، ومباشر لـ **عبدالمحسن الغامدي | محلل بيانات (Data Analyst)**، مبني بالكامل باستخدام **HTML5 و CSS3 فقط**.

---

## 🌟 مميزات التصميم البسيط

- **تركيز مباشر 100%**: يركز فقط على **النبذة التعريفية**، **معرض المشاريع**، و**طرق التواصل المباشرة**.
- **بدون تعقيدات أو تفاصيل CV موسعة**: تجربة تصفح سريعة وخفيفة تبرز مشاريعك وأدواتك التحليلية الأساسية.
- **عرض واضح للمشاريع**: بطاقات مرتبة لمشاريع (Power BI, Python, Excel) مع روابط الكود والمعاينة.
- **تجاوب تام وألوان مريحة**: يعمل بسلاسة على الهواتف الذكية والحواسيب.

---

## 📁 هيكل الموقع

```
Mhsen-work/
│
├── index.html       # هيكل الصفحة وكافة الأقسام والنصوص
├── style.css        # التنسيقات ونظام الألوان والتجاوب
└── README.md        # دليل التخصيص والاستخدام
```

---

## 🛠️ كيف تعدل على الموقع؟

1. **تعديل النبذة**:
   - افتح `index.html` وتوجه إلى قسم `id="about"` لتعديل النص التعريفي.

2. **تعديل المشاريع أو إضافة مشروع جديد**:
   - في قسم `id="projects"`، يمكنك تعديل عنوان أي مشروع، وصفه، الوسوم، أو روابط GitHub والمعاينة.

3. **تعديل بيانات التواصل**:
   - في قسم `id="contact"`، ضع بريدك ورقم هاتفك وروابط حساباتك (LinkedIn و GitHub).

---

## 🌐 تشغيل الموقع
انقر مرتين على ملف `index.html` ليفتح مباشرة في المتصفح!
